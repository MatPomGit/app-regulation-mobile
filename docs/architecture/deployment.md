# Topologia

Lokalna aplikacja Android, bez wdrożonej usługi backendowej. Gradle buduje pięć osobnych wariantów z odrębnymi sufiksami applicationId. CI działa na efemerycznym runnerze, bez podpisywania badawczego i bez publikacji. Instalacja, test fizyczny i dystrybucja pozostają osobnymi bramkami.
