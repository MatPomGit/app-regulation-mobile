# Kompatybilność

| Środowisko | Deklaracja | Stan |
| --- | --- | --- |
| Android | minSdk 26, targetSdk 37 | NOT_RUN na urządzeniu |
| Kompilacja | API 37.0, JDK 17, Gradle 9.6.0 | CI wymagane |
| Kotlin/Compose | Kotlin Compose plugin 2.4.21 | CI wymagane |
| SQLite | Android SQLite; testy JVM przez JDBC | test urządzenia NOT_RUN |
| Kamera, AR, EEG | warianty eksperymentalne | kwalifikacja NOT_RUN |

Wersje są deklaracjami konfiguracji, nie gwarancją wsparcia wszystkich urządzeń.
